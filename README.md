# Haunt — versões publicadas

Este repositório só guarda as versões prontas do **Haunt**, o reprodutor de vídeo para projetor e TV Android.

- Cada versão em **Releases** traz o APK (`Haunt-1.0.N.apk`) e a nota do que mudou.
- O próprio app consulta a última versão daqui (Ajustes > Procurar atualização) e oferece a instalação.
- Não há código-fonte aqui, nem nenhuma configuração ou senha de quem usa o app.

Para instalar à mão: baixe o APK da versão mais recente em Releases, copie para o aparelho e abra pelo gerenciador de arquivos.
